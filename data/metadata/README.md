# Dataset metadata

The shared dataset manifest is generated after the AT&T/ORL images are placed under `data/raw/att_faces/`.

The default manifest contains 100 records:

- `s1`–`s10`
- images `1`–`10` for each subject
- images `1`–`7`: training
- images `8`–`10`: testing

The split is a repository-level reproducibility choice. It is not claimed to be the split used in the original 2014 project.
